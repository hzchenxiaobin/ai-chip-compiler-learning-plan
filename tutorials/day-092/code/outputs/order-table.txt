循环顺序与访存行为对照表（第 92 天交付物）
环境：Linux aarch64, Python 3.11.4, numpy 1.26.4; 本机未安装 MLIR（Day 57~91 口径：Python 复刻 DialectConversion 语义仿真）

贯穿小例：A(2,3) @ B(3,2) → C(2,2)，种子 92（流量与复用距离在此测量）
缓存模拟：A(16,16) @ B(16,16)，直接映射，行 16B（4×f32），矩阵间隔 1 行
  容量：32 行=512B / 64 行=1KB / 128 行=2KB / 256 行=4KB；write-allocate；无预取
  口径：对解释执行器的真实访存日志回放——是模拟测量，不是任何真实硬件的实测

总纲：A、B 的 load 总数与顺序无关（恒 2·M·N·K）；顺序改变的是三件事——
  ① 最内层下标决定每次访问的步长（空间局部性：seq 连续 / stride 跨行 / fixed 不变）
  ② k 的位置决定累加器住哪（寄存器 iter_args vs 内存 RMW → C 流量 MN vs 2·MNK+MN）
  ③ 外层排列决定同一格何时重访（时间局部性：复用距离）

==============================================================================
顺序 i-j-k：for i { for j { for k { … } } }（k 最内层）
==============================================================================
结构    ：18 op（18：k 在最内层，Day 89/90 同构）
累加器  ：寄存器（iter_args %acc，k 内层）
清零    ：不需要——%zero 作为 iter_args 初值出门（Day 87）
最内层 k 扫描时：A seq｜B stride:N｜C 不进体（累加在寄存器）
步长实测：A seq｜B stride:2｜C读 none｜C写 seq（含清零段另计 0 次连续 store）
流量实测（小例）：A load 12｜B load 12｜C load 0｜C store 4（公式：0 读 + M·N 写）
复用距离实测（小例）：A 最近重访均值 7.0 次访问｜B 14.0 次（预测 2*K+1 / N*(2*K+1)）
缓存模拟（16³）：32行 4764 miss（56%）｜64行 950 miss（11%）｜128行 422 miss（5%）｜256行 192 miss（2%）
语义    ：与同序参考位等价 = True
==============================================================================
顺序 i-k-j：for i { for k { for j { … } } }（j 最内层）
==============================================================================
结构    ：21 op（21：主循环 18 + 清零 nest 3）
累加器  ：内存（C[i,j] 逐趟 load→addf→store）
清零    ：需要——init nest 铺 4 次 store
最内层 j 扫描时：A fixed｜B seq｜C seq
步长实测：A fixed｜B seq｜C读 seq｜C写 seq（含清零段另计 4 次连续 store）
流量实测（小例）：A load 12｜B load 12｜C load 12｜C store 12（公式：M·N·K 读 + (M·N·K+M·N) 写）
复用距离实测（小例）：A 最近重访均值 4.0 次访问｜B 24.0 次（预测 4 / 4*K*N）
缓存模拟（16³）：32行 2580 miss（16%）｜64行 1584 miss（10%）｜128行 1233 miss（7%）｜256行 192 miss（1%）

读表三问：
  ① 同一列纵向比：最内层换成 j（ikj/kij），B 从跳 N 变连续 +1，C 从不进体变连续 RMW；
  ② C 流量列：k 内层两家 0L+4S，k 外层四家 12L+12S＋4 清零——k 的位置一个决定，
     C 流量从 4 次写暴涨到 28 次访问（7 倍）；
 ③ miss 列横向看：512B 时连续派（ikj/kij）赢；1KB 时寄存器派（ijk/jik）反超——
    最优顺序取决于「缓存容量 vs 工作集」的相对大小，这正是 Tiling 要解决的问题（Day 94）。
