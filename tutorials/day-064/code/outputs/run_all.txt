== 2. mini.transpose：Permutation 属性与四关 Verifier ==
Operation（IR 文本）：%t = mini.transpose %in permutation = [1, 0] : (2x3xf32) -> (3x2xf32)
属性 permutation = [1, 0]，秩 2，是双射，逆排列 = (1, 0)，阶 = 2
推导：out_shape = in_shape[perm[i]] = (3, 2)
视图配方：out_strides = in_strides[perm[i]] = (1, 3)
Verifier 裁决：合法（0 条错误）
[PASS] 2D 转置 op：打印→解析往返一致
[PASS] 2D 转置 op：Verifier 通过

四关各自的报错现场（检查顺序 E1→E2→E3→E4，值取自真实构造）：
  E1 长度: perm=[0, 1, 2] result=[3, 2, 1] ← 排列比输入多一维
        mini 报错: [E1] 排列长度 3 与输入秩 2 不相等：permutation 必须给每一个输入维安排一个去处
  E2 值域: perm=[2, 0] result=[3, 2] ← 拿 2 去查 2 维输入的 shape——linalg 在这里读到乱码（段 6）
        mini 报错: [E2] 排列第 0 项 2 超出输入秩 2 的合法范围 0..1：拒绝，而不是拿它去查维度
  E3 双射: perm=[1, 1] result=[3, 3] ← 输入维 1 被用了两次，维 0 没了去处
        mini 报错: [E3] 排列 [1, 1] 不是 2 个维度的双射（重复项 [1]）：同一输入维不能被用两次
  E4 形状: perm=[1, 0] result=[2, 3] ← 排列合法，但结果类型写错（应为 3x2）
        mini 报错: [E4] 结果第 0 维应为 3（= 输入第 1 维），实际写的 2：约定 out_shape[i] = in_shape[perm[i]]
[PASS] 四关全部命中且只报本关错误（E4 可报多个失配维）

恒等排列：合法但什么都没做（今天接受，明天 Day 65 的消除对象）：
  %t = mini.transpose %in permutation = [0, 1] : (2x3xf32) -> (2x3xf32)  → Verifier: 合法（no-op）
[PASS] 恒等排列合法（语义正确，收益问题留给 Canonicalizer）
