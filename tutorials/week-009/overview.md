> 第三阶段：AI 计算图与图优化（第 57～84 天）

### 第 057 天｜逻辑 Shape 与物理布局

- **学习**：Shape、Stride、Storage Offset 和 Contiguous 的关系。
- **实践**：用同一底层存储构造连续 Tensor 和转置视图，打印每个元素的物理偏移。
- **产出**：布局示例、偏移计算测试和示意图。

### 第 058 天｜NCHW、NHWC 与编译器 Layout

- **学习**：逻辑维序和物理 Layout 的差异，Layout 对数据复用和向量化的影响。
- **实践**：选择一个二维或四维示例，比较两种 Layout 下连续访问的元素集合。
- **产出**：Layout 对照表和访存序列示例。

### 第 059 天｜Reshape 合法性

- **学习**：元素数量不变、连续性和“仅修改元信息”的关系。
- **实践**：为 `mini.reshape` 增加元素数量和 Shape 检查；明确非连续输入的处理策略。
- **产出**：Reshape Verifier、合法和非法测试。

### 第 060 天｜Broadcast 规则

- **学习**：从右对齐比较维度、维度为 1 的扩展和未知维度处理。
- **实践**：独立实现 Broadcast 输出 Shape 推导，并用 NumPy 或 PyTorch 对照。
- **产出**：Broadcast 推导函数和至少 10 组测试。

### 第 061 天｜动态 Shape 表示

- **学习**：动态维度、符号维度和运行期 Shape 参数；区分“未知”与“任意”。
- **实践**：扩展测试 IR，让 MatMul 的 M 或 N 为动态维度，检查 Verifier 和推导不崩溃。
- **产出**：动态 Shape IR、约束说明和测试。

### 第 062 天｜静态 Shape 特化入口

- **学习**：Shape 特化的收益、编译产物数量和通用实现回退。
- **实践**：设计 `specialize-shape` 命令行选项，将给定动态维度替换为具体值并重新验证。
- **产出**：最小 Shape 特化工具和特化前后 IR。

### 第 063 天｜第 9 周复盘

- **学习**：串联 Shape、Stride、Layout、Broadcast 和动态维度。
- **实践**：用同一个 Tensor 示例解释“Shape 相同但内存布局不同”和“动态维度不等于没有约束”。
- **产出**：一页复盘和本周全部测试。
