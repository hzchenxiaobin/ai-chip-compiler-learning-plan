## 【存疑】

#### 1. “昇腾算子验证里 ULP 的典型用法……常写成误差 ≤ 4 ULP”缺少可核实出处
- **原文**：“昇腾算子验证里 ULP 的典型用法：FP32 输出的数学算子（Exp、Sin、Rsqrt 这类）验收标准常写成"误差 ≤ 4 ULP"。”
- **依据**：glibc/musl 的 libm 测试确实以 ULP 计误差，“≤4 ULP”也是业界常见的数学函数验收档位；但“昇腾算子验证”这一具体绑定（CANN 侧验收是否以此为准）在本环境无法核实，未找到官方文档出处。教程自身的 TOLERANCES 用 max_ulp=4 与该说法自洽，但作为针对昇腾的事实断言建议补充出处，或弱化为“业界常见做法”。
- **置信度**：中（断言合理，但无法在当前环境验证，不判定其必错）。

#### 2. 代码 docstring 把“位模式→单调整数”折叠技巧归因为“Goldberg 的经典折叠”，论文原文未见此技巧
- **原文**：“怎么数格子？技巧是把浮点位模式映射成单调整数（图 3 右半）：正数的编号 = 位模式加 2^(n-1)，负数折叠。”
- **依据**：`ref_check.py` 第 64 行注释称“规则（Goldberg 的经典折叠）”。已核对 Goldberg 1991《What Every Computer Scientist Should Know About Floating-Point Arithmetic》全文（Oracle 在线版）：论文仅在“非负实数的数值序与其浮点表示的字典序对应”一处涉及有序性（脚注 3 只谈字段排列假设），全文未出现针对负数的折叠映射或单调整数编号技巧（"monotonic"一词全文 0 次）。该技巧更常见的出处是浮点数比较类文章（如 Bruce Dawson 2012《Comparing Floating Point Numbers, 2012 Edition》）。技巧本身正确（本报告已另行验证映射的单调性、±0 同号编号与 uint64 无溢出），但归因缺乏依据，建议删去人名或改引可靠出处。
- **置信度**：中高（已全文检索论文未见；不排除 Goldberg 其他著作有类似表述，当前引用无法支撑）。
