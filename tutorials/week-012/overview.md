> 第三阶段：AI 计算图与图优化（第 57～84 天）

### 第 078 天｜浮点表示与累加误差

- **学习**：FP32、FP16、BF16 的位数、范围和精度；累加顺序对结果的影响。
- **实践**：用不同顺序累加同一组浮点数，比较绝对误差和相对误差。
- **产出**：数值实验脚本和结果表。

### 第 079 天｜参考实现与误差指标

- **学习**：Golden Reference、绝对误差、相对误差、ULP 的适用场景。
- **实践**：建立 NumPy 或 PyTorch 参考结果，实现统一误差检查函数。
- **产出**：参考测试工具和不同 Dtype 的阈值配置。

### 第 080 天｜FP16／BF16 测试

- **学习**：低精度输入、高精度累加和输出舍入。
- **实践**：对同一 MatMul 使用不同输入精度和累加精度，记录误差与性能数据。
- **产出**：精度对照表和结论。

### 第 081 天｜INT8 量化基础

- **学习**：Scale、Zero Point、对称／非对称量化和饱和。
- **实践**：实现一个简单的 Per-tensor 量化与反量化函数，测试边界值。
- **产出**：量化工具函数和单元测试。

### 第 082 天｜量化图中的 Cast 与 QDQ

- **学习**：Quantize、Dequantize、Cast 冗余消除的语义边界。
- **实践**：分析 `Q → DQ`、连续 Cast 和低精度算子周围的转换，列出可安全优化与不可优化的情况。
- **产出**：优化规则表，不急于实现不安全 Pattern。

### 第 083 天｜第三阶段集成验收

- **学习**：回顾 Shape、Layout、图优化、Cost Model 和数值验证。
- **实践**：对一张包含 Transpose、Reshape、MatMul、Bias、Relu 的图执行优化并验证结果。
- **产出**：端到端图优化示例、IR 对照、参考结果和全部测试。

### 第 084 天｜第 12 周复盘

- **学习**：总结图编译器不仅做模式匹配，还要管理布局、资源和数值语义。
- **实践**：用 20 分钟讲解当前项目，补充讲不清楚的 Layout 或量化问题。
- **产出**：第三阶段总结和一份“优化正确性检查清单”。
