缓存收益实验：blocking 兑现 Day 92 的预言（真实访存轨迹回放）
环境：Linux aarch64, Python 3.11.4, numpy 1.26.4; 本机未安装 MLIR（Day 57~93 口径：Python 复刻 DialectConversion 语义仿真）

形状 A(16,16) @ B(16,16)；直接映射；行 16B；矩阵间隔 1 行（Day 92 口径）
基线：untiled i-j-k（Day 92 的 512B 灾难户）与 i-k-j（Day 92 的 512B 赢家）
tiled：块循环×3 + 点循环×3；配置 2x2x2 / 4x4x4 / 8x8x8

配置                  总访问     512B缺失    1KB缺失    4KB缺失    B缺@512B   命中率@512B    
untiled i-j-k       8448    4764      950      192      4096      43.6%
untiled i-k-j       16640   2580      1584     192      1120      84.5%
tiled 2x2x2         12544   2236      1294     192      1144      82.2%
tiled 4x4x4         10496   1082      823      192      398       89.7%
tiled 8x8x8         9472    1238      951      192      446       86.9%

三个读数（数字全部来自真实回放）：
  ① B缺：untiled i-j-k 4096 → tiled 4x4x4 398——列面板装进缓存，B 的复用从『靠外层轮回』变『块内四连』；
  ② 512B 总缺失：4764 → 1082；1KB：950 → 823——两个容量档都占优；
  ③ 代价：总访问 8448 → 10496（+24%，来自 C 的跨块 RMW）——多做的访问几乎全部命中，划算。

注：直接映射、无预取、无写缓冲——数字只用于配置之间的对比（Day 92 口径）；
    最优块尺寸取决于『缓存容量 vs 每块工作集』——这是 Day 97 多配置实验的主菜。
