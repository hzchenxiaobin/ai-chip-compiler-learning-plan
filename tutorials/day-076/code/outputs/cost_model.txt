== 1. 接口卡与假设清单（Cost Model v0.1）==
  CostModel 字段：machine=toy-core v0（target 绑定，E1），min_concurrency=3（D73 舒适区）
  evaluate(self, c: 'FusionCandidate', mode: 'str' = 'auto') -> 'CostReport'；can_fuse(c: 'FusionCandidate') -> 'LegalityReport'（不吃机器卡——接口纪律沿用 D74/D75）
  模式：force（合法即融，评分照记）/ auto（评分 > 0 ∧ 零 spill ∧ 寄存器并发 ≥ 3）
  E1 机器假设卡沿用第 73 天（64 KiB 寄存器堆 / 192 KiB SRAM / 64 通道 / fp32），可整体替换重算；CostModel 把卡绑进对象（target 绑定），evaluate 只吃候选＋模式——这是与 D74 should_fuse(c, m) 的接口差别
  E2 计价内核沿用 D72/D73/D75 三本账：keep 形式 ΔB = Σ passes·elems·4（组外使用者只省组内读）；重算形式 elim = (1＋组内＋组外)·elems·4、罚 = 组外数 × 生产者输入字节；spill = 活集三级阶梯 → 两趟税（下界口径）
  E3 统一评分 score = 收益项 − 代价项（单位字节）。只对「有账」的项计价；并行度 / launch / 编译时间 / 多核竞争未计价（C8 沿用）——未计价项只报告，不编数字（D75 的纪律）
  E4 记账执行器 = D72 仪器化执行器去掉数值部分（数值语义 D50/52 已证）：按 kernel 边界记 DRAM 读写；重算形式假设组外使用者把生产者含进自己的 kernel（中间在其内部也不落盘）。对拍只覆盖流量项，不覆盖 spill（容量模型只在 cost model 里——这正是「对拍证明了什么」的边界）
  E5 auto 硬门槛 = 评分 > 0 ∧ 零 spill ∧ 寄存器并发 ≥ 3。寄存器并发 = 寄存器堆 ÷ 单 tile 占用（D73 的 reg_cap，活集口径：融合核工作集装得下几份）；输入分块超 SRAM（staging 失败）损失的是复用不是工作集——只作警告。门槛集与 D75 案例库 ground truth 对齐：R4（工作集顶爆寄存器堆）拒、R3keep（staging 失败）仍融
  E6 决策在候选**声明的形式**（form 字段）上做；形式排序只输出提示——换形式 = 改写候选图（谁读谁不读变了），是后续 Pattern 的工作
  E7 force 模式只看合法性（合法即融），评分照记——它是 A/B 校准与误差测量的工具，不是生产模式；默认模式必须是 auto
  E8 误差四轴：口径（spill 下界、不计 launch）/ 参数（机器卡是假设的）/输入（动态 Shape → 评分未知）/ 未计价（并发等）。今天的两个实弹只演示参数轴（换卡翻转 R4）与输入轴（动态 Shape 拒之门外）
[PASS] 1a 接口纪律：can_fuse 不吃机器卡；evaluate 吃候选＋模式，不吃账本
[PASS] 1b 假设清单 E1–E8 共 8 项，覆盖四类误差来源（口径/参数/输入/未计价）
[PASS] 1c 未知模式直接报错（不静默回落）

  // 融合前：3 个独立 kernel；中间 %c、%e 落盘（写 1 遍 + 被读 N 遍）
  func.func @main(%a: memref<2x3xf32>, %b: memref<3x2xf32>, %d: memref<2x2xf32>) -> memref<2x2xf32> {

    mini.matmul ins(%a: memref<2x3xf32>, %b: memref<3x2xf32>) outs(%c : memref<2x2xf32>)
    %e = memref.alloc() : memref<2x2xf32>            // 中间落盘
    mini.add ins(%c: memref<2x2xf32>, %d: memref<2x2xf32>) outs(%e : memref<2x2xf32>)
    %f = memref.alloc() : memref<2x2xf32>
    mini.relu ins(%e: memref<2x2xf32>) outs(%f : memref<2x2xf32>)
    return %f : memref<2x2xf32>
  }

  // 融合后（keep 形式）：1 个 kernel；中间只活在核内（寄存器），ΔB = 64 B
  func.func @main(%a: memref<2x3xf32>, %b: memref<3x2xf32>, %d: memref<2x2xf32>) -> memref<2x2xf32> {
    %f = memref.alloc() : memref<2x2xf32>
    mini.fused_matmul_bias_relu ins(%a: memref<2x3xf32>, %b: memref<3x2xf32>, %d: memref<2x2xf32>) outs(%f : memref<2x2xf32>)
    return %f : memref<2x2xf32>
  }
