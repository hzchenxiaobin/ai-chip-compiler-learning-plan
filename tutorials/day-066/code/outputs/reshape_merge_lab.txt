== 2. Reshape 语义：元素数量守恒 + 三关 Verifier ==
  判据只有一个数：prod(in_shape) == prod(out_shape)（元素数量守恒）
  verify_reshape((2, 3, 4), (5, 7), 'C') → [E2] 元素数量不守恒：输入 24 ≠ 输出 35
  verify_reshape((2, 3, 4), (0, 6), 'C') → [E1] 输出第 0 维 0 < 1（mini 每维须为 ≥1 整数）
  verify_reshape((2, 3, 4), (24,), 'A') → [E3] 未知 order = 'A'（mini 只认 'C' / 'F'）
[PASS] E1/E2/E3 反例全部被三关 Verifier 拦截
[PASS] E2 正例：(2,3,4) → (6,4) → (24,) 每跳 numel 都是 24

  物理代价现场（numpy 1.26.4 实测，reshape 是视图还是拷贝？）：
    连续输入 B --reshape--> (6,4)：shares_memory = True（视图）
    非连续输入 B.T --reshape--> (6,4)：shares_memory = False（被迫拷贝一次）
    二跳 (6,4) --reshape--> (24,)：shares_memory = True（视图）
    合并一步 B.T --reshape--> (24,)：也是一次拷贝，值与两跳相等 = True
[PASS] C 序链的物理代价：连续输入全视图；非连续输入至多第一跳拷贝一次，合并一步拷贝次数相同

== 3. mini 侧：P1 恒等消除 + P2 链合并的现场 ==
Pattern 1（恒等消除）：Reshape(x, shape(x)) → x——不需要唯一使用者检查
Pattern 2（链合并）：Reshape(Reshape(x, s1), s2) → Reshape(x, s2)——中间值唯一使用者

场景 A（恒等单跳，结果被 2 个消费者 + 0 return 使用 → P1 照样消除）：
  %in : shape (2, 3, 4) （func 入参，值可由 numpy 提供可见性）
  %r = mini.reshape %in shape = [2, 3, 4] order = "C" : (2x3x4xf32) -> (2x3x4xf32)
  %a = mini.reshape %r shape = [24] order = "C" : (2x3x4xf32) -> (24xf32)
  %b = mini.reshape %r shape = [4, 6] order = "C" : (2x3x4xf32) -> (4x6xf32)
  func.return %a, %b
  %r 的使用者数 = 2（%a、%b 各一）——P1 不看这个
→ PassManager 2 轮、应用 1 次：
  %in : shape (2, 3, 4) （func 入参，值可由 numpy 提供可见性）
  %a = mini.reshape %in shape = [24] order = "C" : (2x3x4xf32) -> (24xf32)
  %b = mini.reshape %in shape = [4, 6] order = "C" : (2x3x4xf32) -> (4x6xf32)
  func.return %a, %b
[PASS] A：恒等消除不看使用者数（op 数 3→2），%a/%b 全部改道读 %in

场景 B（朴素链 B --(6,4)--> --(24,)-->，P2 合并跳过中间形状）：
  %in : shape (2, 3, 4) （func 入参，值可由 numpy 提供可见性）
  %t = mini.reshape %in shape = [6, 4] order = "C" : (2x3x4xf32) -> (6x4xf32)
  %c = mini.reshape %t shape = [24] order = "C" : (6x4xf32) -> (24xf32)
  func.return %c
→ PassManager 2 轮、应用 1 次：
  %in : shape (2, 3, 4) （func 入参，值可由 numpy 提供可见性）
  %c = mini.reshape %in shape = [24] order = "C" : (2x3x4xf32) -> (24xf32)
  func.return %c
[PASS] B：朴素链合并为单 reshape（op 数 2→1，直读 %in，shape=[24]）

场景 C（绕回链 B --(6,4)--> --(2,3,4)-->，合并成恒等 → 整体消除）：
  %in : shape (2, 3, 4) （func 入参，值可由 numpy 提供可见性）
  %t = mini.reshape %in shape = [6, 4] order = "C" : (2x3x4xf32) -> (6x4xf32)
  %c = mini.reshape %t shape = [2, 3, 4] order = "C" : (6x4xf32) -> (2x3x4xf32)
  func.return %c
→ PassManager 2 轮、应用 1 次：
  %in : shape (2, 3, 4) （func 入参，值可由 numpy 提供可见性）
  func.return %in
[PASS] C：绕回链整体消除（op 数 2→0，链尾形状 == 输入形状）

场景 D（五连链 B→(6,4)→(24,)→(2,12)→(24,1)→(12,2)，迭代到单 op）：

场景 E（多使用者反例：%t 被 %c、%u 两个消费者用 → P2 拒绝，图不动）：
