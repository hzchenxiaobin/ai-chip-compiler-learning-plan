== 1. 手工推导：Transpose 穿过逐元素算子（T(E(x)) ≡ E(T(x))） ==
========================================================================

推导（只用一条性质）：
  约定（Day 64）：T_p(A) 的第 i 根轴 = A 的第 p[i] 根轴；
                 取值时索引按轴对应关系跟着换（记 q = p^-1）：
                 T_p(A)[i0..in-1] = A[i_{q(0)}..i_{q(n-1)}]
  左边：T_p(Relu(x))[idx] = Relu(x)[idx∘q] = relu( x[idx∘q] )
                              ~~~~~~~~~~~~ 逐元素：Relu(A)[任何位置] = relu(A[该位置])
  右边：Relu(T_p(x))[idx]  = relu( T_p(x)[idx] ) = relu( x[idx∘q] )
  两边逐位置相等。∎
  唯一用到的性质：E(A)[idx] = e(A[idx])——「逐位置不变性」。
  谁没有这条性质，谁就不能被穿过（第 4 节的反例都从这查）。

贯穿例子（B(2,3)，p=(1,0)）：
  T(Relu(B)) =
[[0.  3.5]
 [0.5 0. ]
 [2.  0. ]]
  Relu(T(B)) =
[[0.  3.5]
 [0.5 0. ]
 [2.  0. ]]
[PASS] 推导-数值对拍 T(Relu(B)) == Relu(T(B))
[PASS] 推导-数值对拍 T(Neg(B)) == Neg(T(B))

  位置追踪（q = p^-1 = (1, 0)）：
    输出位置 (0, 1) ← 两边都取 relu(B(1, 0)) = relu(3.5) = 3.5
    输出位置 (2, 0) ← 两边都取 relu(B(0, 2)) = relu(2.0) = 2.0
    输出位置 (2, 1) ← 两边都取 relu(B(1, 2)) = relu(-2.5) = 0.0
[PASS] 推导-追踪表 3 个位置与矩阵值一致
[PASS] 推导-随机对拍 10 组（rank 2~4 随机 perm）（10/10）

== 4. 语义约束说明（今日产出）：能穿 / 不能穿 / 什么时候不许动 ==
========================================================================

判据只有一条：E(A)[idx] = e(A[idx])（逐位置不变性）。
  ✓ relu / neg        逐位置同函数 —— 直接穿
  △ add              合法但要「两侧同 perm」：T(Add(a,b)) = Add(T(a),T(b))，
                       第二个操作数要新转置（常量可折，张量要算账）
  ✗ reduce_sum        跨位置求和：正确推法要把 axis 重映射为 p^-1(k)，
                       同 axis 硬推会被 shape 检查抓住（下面实测）
  ✗ reshape           位置重新线性化：即使 shape 对得上，值也可能错（反例）
  ✗ conv / matmul     跨位置加权混合（本周不展开，同属「不能穿」家族）
[PASS] 约束-reduce 不在白名单，Pattern 拒绝

  reduce 反例（axis=0，p=(1,0,2)，p[0]=1 ≠ 0=k）：
    正确结果 shape (3, 1, 4)
    同 axis 硬推 shape (1, 2, 4) —— shape 检查当场抓住
    （若 p 恰好固定 k，如 p=(0,2,1)，重映射 p^-1(k)=k 与原 axis 重合，是「碰巧正确」的边界，不能证明合法性）
[PASS] 约束-reduce 同 axis 硬推 shape 不一致
[PASS] 约束-reduce 正确重映射公式 T(reduce(x,k)) == reduce(T(x), p^-1(k))（20 组随机）

  reshape 反例（x 2x3 -> reshape 3x2 -> T；对比 T -> reshape 2x3）：
    左边 =
[[1. 3. 5.]
 [2. 4. 6.]]
    右边 =
[[1. 4. 2.]
 [5. 3. 6.]]
[PASS] 约束-reshape 同 shape 不同值（位置重新线性化）
[PASS] 约束-add 数学上可穿（两侧同 perm）

  add 的账：另一个操作数是常量 → 转置可折进常量（免费）；是张量 → 要新增一个转置（第 5 节选做挑战再算）

  方向门（同图双向规则）：2 轮后状态 = oscillation（状态哈希回到已见过的值——互相 undo，永不收敛）
[PASS] 约束-双向规则振荡被检测
[PASS] 约束-单方向规则正常收敛（1 轮）
