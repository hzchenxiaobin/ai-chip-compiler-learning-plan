> 第五阶段：端到端编译与 Runtime（第 113～140 天）

### 第 120 天｜设计命令行接口

- **学习**：编译器 CLI 的输入、输出、选项、诊断和退出码。
- **实践**：定义输入文件、输出目录、优化开关、Tile 参数和 Dump 选项。
- **产出**：CLI 参数说明和帮助文本。

### 第 121 天｜整合图优化 Pass

- **学习**：Pass 管道的稳定顺序和重复执行问题。
- **实践**：接入 Shape 推导、图简化、融合和收益判断，支持分别开关。
- **产出**：图优化管道及开关对照测试。

### 第 122 天｜整合循环与 LLVM Lowering

- **学习**：Conversion 失败时如何保留诊断并停止后续执行。
- **实践**：接入 MatMul 循环生成、Tiling 和 LLVM Lowering，处理不支持场景。
- **产出**：完整编译管道和失败诊断测试。

### 第 123 天｜IR Dump 与可观测性

- **学习**：阶段 Dump、Pass 日志和调试信息的可读性。
- **实践**：为每个关键阶段输出独立 IR 文件，文件名包含阶段序号。
- **产出**：可自动生成的 IR 阶段序列和调试说明。

### 第 124 天｜端到端 MatMul＋Bias＋Relu

- **学习**：融合算子如何映射到实际循环或运行库实现。
- **实践**：打通目标项目整条链路，并与 NumPy 或 PyTorch 结果比较。
- **产出**：首个完整项目可运行版本。

### 第 125 天｜优化开关对照实验

- **学习**：控制变量和端到端性能归因。
- **实践**：分别测试无优化、仅图优化、图优化＋Tiling、完整优化，记录正确性和性能。
- **产出**：四组 IR、性能数据和阶段收益表。

### 第 126 天｜第 18 周复盘

- **学习**：总结统一编译入口、诊断和实验可重复性。
- **实践**：按 README 从干净目录重新构建并运行一次。
- **产出**：可复现说明和本周复盘。
