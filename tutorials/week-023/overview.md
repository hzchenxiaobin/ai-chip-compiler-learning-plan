> 第六阶段：项目收口与面试转化（第 141～168 天）

### 第 155 天｜整理项目架构

- **学习**：架构图应表达职责和数据流，而不是堆叠文件名。
- **实践**：绘制前端输入、图 IR、优化、循环 IR、LLVM、Runtime 的架构图。
- **产出**：一张项目总架构图和模块职责表。

### 第 156 天｜整理关键 Pass

- **学习**：Pass 文档需要说明输入、输出、合法性、收益和限制。
- **实践**：为 Shape 推导、融合、Layout 优化、Tiling 各写一份简要说明。
- **产出**：关键 Pass 文档和优化前后 IR 示例。

### 第 157 天｜整理 Lowering 文档

- **学习**：Lowering 文档应解释抽象如何逐级消失、语义如何保持。
- **实践**：用一个 MatMul 示例串联各阶段 IR，标注关键转换。
- **产出**：Lowering 流程图和阶段 IR 文件。

### 第 158 天｜整理测试文档

- **学习**：测试金字塔、正负例、随机测试和性能回归。
- **实践**：列出测试分类、运行命令、覆盖范围和当前缺口。
- **产出**：测试说明和一键回归命令。

### 第 159 天｜整理性能材料

- **学习**：性能结果必须附输入、配置、环境和统计口径。
- **实践**：汇总 Tile、融合、Shape 特化和最终优化的性能数据，生成图表。
- **产出**：性能表格、图表和结论摘要。

### 第 160 天｜干净环境复现

- **学习**：可复现性是工程项目验收的一部分。
- **实践**：按 README 从干净目录执行构建、测试、编译和 Benchmark，修复遗漏步骤。
- **产出**：完整 README 和复现记录。

### 第 161 天｜第 23 周复盘

- **学习**：检查项目是否既能运行，又能被他人理解和验证。
- **实践**：以第一次接触项目的视角通读文档，删除只对自己有意义的表述。
- **产出**：项目展示版本和剩余问题清单。
