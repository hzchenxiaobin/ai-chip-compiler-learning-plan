贯穿例：A(2,3) @ B(3,2) → C(2,2)（M=N=2、K=3——恰是 M==N 巧合对）
  手画对账：三重循环 [0,2)×[0,2)×[0,3)、配对 A[i,k]/B[k,j]/C[i,j]、
  地址 3i+k / 2k+j / 2i+j、每格 3 项、load 24 / store 4、
  覆盖 A×2 / B×2 / C×1 —— 全部与生成 IR 及访存日志逐条相符（RT2）。

数字面板（全部真实运行）：
  语义条款：S1..S6 = ✓/✓/✓/✓/✓/✓
  行为等价：与同序参考位等价 = True；np.matmul 差值 1.192e-07（舍入顺序不同，不算失败）
  结构不变式：IR 恒 18 op；常量多重集 {0,1,2,2,3}；LoopSpec (i<M, j<N, k<K)
  分辨力：4 变异在复盘例上 = a_swap=OOB / b_swap=OOB / i_ub_n=SAME / k_ub_n=NUM
  全矩阵回归：15/15（Day 90 ST1 原样复跑）
