三种调度的真实时间线（512×512×512，tile 64³，FP32，示例参数）
================================================================================================
指标                               单缓冲(D102)               逐块双缓冲             跨块预取流水线
------------------------------------------------------------------------------------------------

DMA 忙 µs                             544.5               544.5               544.5
DMA 闲置 µs                              512                  64                   1
计算忙 µs                                 512                 512                 512
计算气泡 µs                              544.5                96.5                33.5
计算利用率                               48.46%              84.14%              93.86%

填充(首个计算前) µs                        1.0078              1.0078              1.0078
排空(最后计算后) µs                           0.5                 0.5                 0.5
S1/S2/S3/S4 次数               512/511/64/63       512/510/64/63       512/510/64/63
S2 让 DMA 白等 µs                         448                   0                   0
------------------------------------------------------------------------------------------------
理想重叠下界 = max(DMA忙, 计算忙) = max(544.5, 512) = 544.5 µs（D102 预告的 1.94× 上限）
逐块双缓冲距下界还差 64 µs（64 块 × 1 µs 暴露填充：预取没有跨过块边界）
跨块预取距下界只差 1 µs（全 kernel 唯一一次排空：末圈计算时 DMA 无货可搬）
同步点小结：双缓冲后 S1/S3/S4 一个不少，S2 从 511 → 510
（距离 2 使最初两圈没有前任读者）；真正变化的是 S2 让 DMA
白等的时间：448 µs → 0——覆盖写在读者完工之后，流水线内消化。
