== 2. 组合排列：方向钉死 + 全量对拍 ==
推导：C = T_q(T_p(A))，C.shape[i] = A.shape[p[q[i]]] → r = compose(p, q)，r[i] = p[q[i]]
  p = (1, 2, 0)，inv(p) = (2, 0, 1)，compose(p, inv(p)) = (0, 1, 2)（恒等）
  compose(p, p) = (2, 0, 1)（= inv(p)，3-循环的 p²）
  B(2,3,4) 经 p 三连：(3, 4, 2) → (4, 2, 3) → (2, 3, 4)（回到原形状）

[PASS] 4 元全排列（24 个）：T_p 连做『阶』次回到恒等（k 次自乘 = 恒等）

== 3. mini 侧：两个 RewritePattern 的现场 ==

Pattern 2（一般合并）：T_q(T_p(x))，中间值唯一使用者 → T_{compose(p,q)}(x)（合成恒等则消除）

  %in : shape (2, 3) （func 入参，值可由 numpy 提供可见性）
