    - mini.matmul

        原因：类型转换失败：tensor<4x3xf32>：tensor 是值语义类型，最终 Lowering 的兑换表里没有目标类型——必须先经过第一段 Lowering（bufferize，D85~D105）
  full：同输入 FAIL——两道闸（TypeConverter 拒收 tensor、ConversionTarget 拒收 mini）把管道顺序错误拦在门外
