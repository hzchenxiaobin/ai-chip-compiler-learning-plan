========================================================================
别名约束演示：B 是 A 的视图（同一物理存储），区间分析只看名字
========================================================================

合成用例（Z 长寿命 200 B；A [1,2] 100 B；B [3,4] 60 B，与 A 同存储；
C [2,3] 48 B；D [3,3] 80 B；放置策略 H1，对齐 4 B）

[错误示范] 不合并别名组，把 A、B 当两个独立缓冲区规划：
  Z  200 B  [1, 5]  偏移 0
  A  100 B  [1, 2]  偏移 200
  D   80 B  [3, 3]  偏移 200
  C   48 B  [2, 3]  偏移 300
  B   60 B  [3, 4]  偏移 348
  workspace 408 B
  ✗ 校验失败：别名组 {A,B} 偏移不一致：[200, 348]
  （投毒模拟反而通过：两个名字落在不同字节，谁也没覆盖谁——
    真正的错误是语义：步骤 1 通过 A 写进偏移 200 的字节，
    步骤 3~4 却通过 B 去读偏移 348 的字节，读到的是未初始化数据。）

[正确做法] 先合并别名组，再参与放置：
  存储单元 S{A,B}：区间 = [1,2] ∪ [3,4] = [1, 4]（并集），大小 = max(100, 60) = 100 B
  Z         200 B  [1, 5]  偏移 0
  {A,B}     100 B  [1, 4]  偏移 200   ← A、B 同偏移
  C          48 B  [2, 3]  偏移 300
  D          80 B  [3, 3]  偏移 348
  workspace 428 B
  静态检查 通过；别名组偏移一致 通过；投毒模拟（12 次校验）通过
  → 全部通过；workspace 只比错误示范多 20 B，换来语义正确。
