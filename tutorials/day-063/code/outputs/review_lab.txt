主角登场：A = [[1, 2, 3], [4, 5, 6]]，shape (2, 3)
六种身份全部由这 6 个数字（和它的存储排列）扮演，公式只有一条：
  物理偏移(idx) = storage_offset + Σ idx[i] × strides[i]

== 1. 命题一 A：同 Shape (2,3)，两种布局 ==
身份 1（行主序）: shape=(2, 3) strides=(3, 1) offset=0 存储=[1, 2, 3, 4, 5, 6]
身份 2（列主序）: shape=(2, 3) strides=(1, 2) offset=0 存储=[1, 4, 2, 5, 3, 6]

逐元素账本（值 @ 物理偏移，括号里是周公式的手算过程）：
  身份1: A[0,0]=1@0(0×3+0×1)  A[0,1]=2@1(0×3+1×1)  A[0,2]=3@2(0×3+2×1)  A[1,0]=4@3(1×3+0×1)  A[1,1]=5@4(1×3+1×1)  A[1,2]=6@5(1×3+2×1)
  身份2: A[0,0]=1@0(0×1+0×2)  A[0,1]=2@2(0×1+1×2)  A[0,2]=3@4(0×1+2×2)  A[1,0]=4@1(1×1+0×2)  A[1,1]=5@3(1×1+1×2)  A[1,2]=6@5(1×1+2×2)

按逻辑读序（行优先）走过的物理偏移序列：
  身份 1（连续）: [0, 1, 2, 3, 4, 5] ← 相邻逻辑元素在内存里也相邻
  身份 2（跳跃）: [0, 2, 4, 1, 3, 5] ← 同样的逻辑读序，物理上蹦着走
[PASS] 1a 两身份 shape 相同且值逐位相等
[PASS] 1b 两身份底层字节不同（不是同一份内存）（S_row=[1, 2, 3, 4, 5, 6] vs S_col=[1, 4, 2, 5, 3, 6]）
[PASS] 1c 两身份 strides 不同（布局不同）
[PASS] 1d 周公式在两身份上逐元素成立（12/12 对账）

== 4. 命题一 D：4D 放大版 —— NCHW vs NHWC（Day 58 同款数据）==

== 6. 命题二：动态维度不等于没有约束（三房间裁决 + 特化复验）==

== 7. 知识时间线：A 的 dim0（M）的四档状态 ==
  档位                写法                                数值何时知道        约束在哪查
  静态 static         memref<2x3xf32>（写死）               写类型那一刻        编译期 Verifier（房间 2 的 exit=1）
  符号 sym（mini）      Sym("M") + 约束表同名对账                编译期只有名字       推导时同名必须相等（Day 61）
  未知 runtime        memref<?x3xf32>（描述符 sizes[0]）     运行期输入到达       运行期检查 / 放行但欠账（房间 1、3）
  特化 specialized    memref<2x3xf32>（观测值钉回）            运行期观测之后       重推 + 重验（6d/6e 的 exit=3/4）
  一句话：? 只隐瞒「数值」，从不豁免「规矩」——rank、静态维、
  运行期取值合法性一条没少，变的只是检查时机与检查者。
