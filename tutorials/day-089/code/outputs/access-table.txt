Day 89 访存日志：逐条地址核对＋覆盖统计（真实运行）
环境：Linux aarch64, Python 3.11.4, numpy 1.26.4; 本机未安装 MLIR（DialectConversion 语义仿真＋访存日志解释执行，不伪造 MLIR 行为）

口径：每条 load/store 记录 (memref, 多维下标, 线性地址, 值)；
      地址独立重算：np.ravel_multi_index(idx, shape, order='C')（Day 85 TP2 的全量版）；
      覆盖统计 = 每个线性地址被访问的次数（A 读 N 次/格、B 读 M 次/格、C 写 1 次/格）。

—— 地址公式（strides 声明在 memref 类型里）——
  A(4, 6) strides (6, 1)：addr = 6·i + k
  B(6, 3) strides (3, 1)：addr = 3·k + j
  C(4, 3) strides (3, 1)：addr = 3·i + j

—— 逐条地址核对：156 条访存全部与独立重算相等 ——
  load 144 条（%a 72 ＋ %b 72）· store 12 条（%c 12）· 未初始化读 0 条

—— 覆盖统计（每个线性地址的访问次数）——
  %a：24 格，每格读 3 次 → 共 72 次（N = 3：A 的元素在所有 j 上被复用）
  %b：18 格，每格读 4 次 → 共 72 次（M = 4：B 的元素在所有 i 上被复用）
  %c：12 格，每格写 1 次 → 共 12 次（只写最终值——store 在 k 外、j 内）

—— 端到端数值 ——
  C 与同序参考实现逐位相等：True
  C 与 np.matmul：逐位相等 = False，max|diff| = 2.384e-07（舍入顺序可能不同，单独报告）
