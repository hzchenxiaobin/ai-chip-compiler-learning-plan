Day 90 猎杀矩阵：4 个注入变异 × 15 组形状（真实运行）
环境：Linux aarch64, Python 3.11.4, numpy 1.26.4; 本机未安装 MLIR（DialectConversion 语义仿真＋访存日志解释执行，不伪造 MLIR 行为）

分类口径：
  OOB  = 按维越界探针拦截（真实报错文本见各行）——执行级证据；
  NUM  = 跑完不崩，但与同序参考实现不等（静默算错）——只有参考对照抓得住；
  SAME = 与参考逐位相同（该形状对此变异免疫/隐身）——盲区，必须记录而不是回避。

── 方阵盲区（ST2）：A(3,3)@B(3,3) 单独一列 ──
  M1 a_swap    NUM   max|C − ref| = 2.199e+00（静默算错）
  M2 b_swap    NUM   max|C − ref| = 1.701e+00（静默算错）
  M3 i_ub_n    SAME  与同序参考逐位相同
  M4 k_ub_n    SAME  与同序参考逐位相同

── 全矩阵（行=形状，列=变异）──
  形状                    M1 a_swap   M2 b_swap   M3 i_ub_n   M4 k_ub_n

── 每个变异的杀伤统计与 OOB 证据 ──
  M1 a_swap（配对写反：load %a[%k, %i]（A 的行列互换；方阵时算 Aᵀ·B，不越界））
    杀 11/15：OOB 9（['1x7x4', '6x1x4', '4x3x1', '2x3x5', '5x2x3', '2x8x3', '4x6x3', '5x2x2', '4x6x4']）＋ NUM 2（['3x3x3', '3x3x5']）
    OOB 证据：memref.load %a(1, 0)：第 0 维下标 1 ∉ [0, 1)（shape (1, 7)）
    NUM 证据：(3, 3, 3)→max|C − ref| = 2.199e+00（静默算错）; (3, 3, 5)→max|C − ref| = 2.680e+00（静默算错）
    SAME 盲区 4 组：标量 (1, 1, 1)、K=0 (4, 0, 3)、M=0 (0, 6, 3)、N=0 (3, 2, 0)

  M2 b_swap（配对写反：load %b[%j, %k]（B 的行列互换；K==N 时算 A·Bᵀ，不越界））
    杀 11/15：OOB 9（['1x7x4', '6x1x4', '4x3x1', '2x3x5', '5x2x3', '2x8x3', '4x6x3', '3x3x5', '4x6x4']）＋ NUM 2（['3x3x3', '5x2x2']）
    OOB 证据：memref.load %b(0, 4)：第 1 维下标 4 ∉ [0, 4)（shape (7, 4)）；线性地址 4 甚至仍在缓冲区（28 格）内——只查线性地址抓不住这类逻辑越界
    NUM 证据：(3, 3, 3)→max|C − ref| = 1.701e+00（静默算错）; (5, 2, 2)→max|C − ref| = 1.810e+00（静默算错）
    SAME 盲区 4 组：标量 (1, 1, 1)、K=0 (4, 0, 3)、M=0 (0, 6, 3)、N=0 (3, 2, 0)

  M3 i_ub_n（边界错绑：i 循环上界绑到 %cN（应绑 %cM）；M==N 时位相同（隐身））
    杀 11/15：OOB 5（['1x7x4', '2x3x5', '2x8x3', '3x3x5', '0x6x3']）＋ NUM 6（['6x1x4', '4x3x1', '5x2x3', '4x6x3', '5x2x2', '4x0x3']）
    OOB 证据：memref.load %a(1, 0)：第 0 维下标 1 ∉ [0, 1)（shape (1, 7)）
    NUM 证据：(6, 1, 4)→max|C − ref| = 9.397e+02（静默算错）; (4, 3, 1)→max|C − ref| = 7.959e+02（静默算错）; (5, 2, 3)→max|C − ref| = 8.729e+02（静默算错）; (4, 6, 3)→max|C − ref| = 8.518e+02（静默算错）; (5, 2, 2)→max|C − ref| = 8.431e+02（静默算错）; (4, 0, 3)→max|C − ref| = 8.540e+02（静默算错）
    SAME 盲区 4 组：方阵对照 (3, 3, 3)、标量 (1, 1, 1)、M==N (4, 6, 4)、N=0 (3, 2, 0)

  M4 k_ub_n（边界错绑：k 循环上界绑到 %cN（应绑 %cK）；K==N 时位相同（隐身））
    杀 10/15：OOB 5（['6x1x4', '2x3x5', '5x2x3', '3x3x5', '4x0x3']）＋ NUM 5（['1x7x4', '4x3x1', '2x8x3', '4x6x3', '4x6x4']）
    OOB 证据：memref.load %a(0, 1)：第 1 维下标 1 ∉ [0, 1)（shape (6, 1)）；线性地址 1 甚至仍在缓冲区（6 格）内——只查线性地址抓不住这类逻辑越界
    NUM 证据：(1, 7, 4)→max|C − ref| = 1.866e+00（静默算错）; (4, 3, 1)→max|C − ref| = 1.835e+00（静默算错）; (2, 8, 3)→max|C − ref| = 5.200e+00（静默算错）; (4, 6, 3)→max|C − ref| = 4.081e+00（静默算错）; (4, 6, 4)→max|C − ref| = 2.934e+00（静默算错）
    SAME 盲区 5 组：方阵对照 (3, 3, 3)、标量 (1, 1, 1)、K==N (5, 2, 2)、M=0 (0, 6, 3)、N=0 (3, 2, 0)

── 读法 ──
  · 每个变异都有自己的盲区形状（标量、退化维、以及各自的巧合对）；
  · 矩阵整体无盲区：4 个变异各被 ≥10 组形状杀死，其中 OOB ≥5（带诊断的执行级
    证据）、NUM ≥2（只有参考对照抓得住的静默算错）；
  · (2,3,5)（M≠K≠N）单枪匹马杀全部 4 个变异——三数互不相等是配对/绑定测试的
    最小充分条件；(1,1,1) 则一个都杀不了——退化形状测管道，不测配对。
