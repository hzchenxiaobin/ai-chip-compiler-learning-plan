[PASS] ST5 退化维 0
  K=0，A(4,0)@B(0,3)：C(4,3) 全零（True）——空归约＝单位元 0：k 零趟，%acc 原样出门；load 0 · store 12（C 每格仍写 1 次）（True）
    D87 的 %zero 初值在此兑现：它是「归约单位元」而不只是「清零习惯」
  M=0，A(0,6)@B(6,3)：C(0,3) 空（shape (0, 3)）；i 零趟 → j/k 从未激活；load 0 · store 0 · alloc 0 格（True）
  N=0，A(3,2)@B(2,0)：C(3,0) 空（shape (3, 0)）；j 零趟（k 因此从未激活）；load 0 · store 0（True）
  三者的 IV 轨迹：K=0 → %k 激活 12 次每次 0 趟；M=0 → %i 激活 1 次 0 趟；N=0 → %j 激活 3 次每次 0 趟——「零趟」由 trip = max(0, ceil((ub-lb)/step)) 保证
  工程边界：空数组 reshape / 空 Counter 的 max() 是这里最常见的坑（见 README 常见错误 E1/E2）

[PASS] ST6 静态前提与事务契约
  A(?x7) @ B(7,4)（1×N 的 M 动态），full 模式：按预期失败（True）——边界形状不豁免静态前提
