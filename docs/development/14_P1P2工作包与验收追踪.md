## 2. 版本与迁移基线

| 数据层 | 版本 | 新增 | 迁移约束 |
|---|---|---|---|
| MySQL/Django ORM | P0 初始 migration | 内容、账号、计划、进度、任务、数据任务 | 严格模式和 InnoDB，迁移可演练 |
| MySQL/Django ORM | WP-08 后续 migration | 题包、attempt、review、stuck、证据基础 | expand→migrate→contract，旧导出可读 |
| MySQL/Django ORM | WP-12 后续 migration | project/version/slot/release | 不重写证据和复习，默认 private |
| 浏览器离线库 | WP-13 可选 v1 | outbox、tombstone、sync_state | 未开启离线不创建；退出清理 |
| 导出 Schema | v1→v2 | attempts/review/stuck/evidence，后续项目 | 完整预检、替换前快照 |
| Attestation | v1 | L2/L3 签名证明 | 不同密钥、kid 轮换、过期与撤销 |
| 服务端 API | `/api/v1/` | 学习/社区/AI/Lab 各自 scope | 不共享数据库超级权限，不混用认证密钥 |

Django migration 编号、导出 Schema 版本和浏览器离线库版本互不绑定。应用回滚选择兼容当前 MySQL Schema 的镜像，不删除新学习数据。旧前端无法识别高版本 outbox 时保持只读，不调用 `deleteDatabase()`。

## 13. 跨版本发布门禁

共有门禁：

- P0 26 用例不回归；证据变更后重跑 TC-F13/F14。
- MySQL migration 使用真实旧版备份/fixture，升级失败不丢数据，旧导出仍可用。
- 新页面完成键盘、读屏、320px、200% 字体和明暗主题检查。
- 新 API 有行级权限、请求大小、分页、限流、CSRF/CORS、审计和故障降级。
- 秘密仅在服务端/密钥系统；浏览器、公开仓库、artifact 和日志扫描通过。
- flag 关闭无死按钮，公开教程和在线学习路径不受影响。
- 回滚不删除高版本 MySQL 数据或 outbox，不通过跳过验签/权限维持可用。

专项门禁：

| 模块 | 必须提交的证据 |
|---|---|
| 自测/复习 | 调度时区、题目版本、先答后看、无断签惩罚 |
| 证据/L2 | 哈希跨实现、篡改拒绝、公开测试边界、密钥轮换 |
| 项目档案 | 默认服务端私密、导出预览、不跨硬件排名 |
| 可选离线 | 双端冲突、删除防复活、pending 导出、退出清理 |
