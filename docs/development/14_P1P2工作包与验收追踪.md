## 2. 版本与迁移基线

| 数据层 | 版本 | 新增 | 迁移约束 |
|---|---|---|---|
| IndexedDB | v1（P0） | progress、meta | 不改 P0 语义 |
| IndexedDB | v2（WP-08） | exercise_attempts、review_items、stuck_items、evidence | 单事务新增；v1 备份继续可导入 |
| IndexedDB | v3（WP-12） | portfolio_items | 不重写证据和复习 |
| IndexedDB | v4（WP-13） | sync_outbox、sync_state | 未开启同步不创建云数据 |
| 备份 | v1→v2 | 新增四类 P1 实体 | 完整预检、替换前全量备份 |
| 备份 | v3/v4 | 档案、必要同步元数据 | outbox 中敏感操作默认不直接导入执行 |
| Attestation | v1 | L2/L3 签名证明 | 不同密钥、kid 轮换、过期与撤销 |
| 服务端 | API v1 | 同步/社区/AI/Lab 各自独立 | 不共享数据库超级权限，不混用认证密钥 |

回滚前端代码不得删除高版本 IndexedDB。旧代码无法识别新版本时保持只读并提示导出，不调用 `deleteDatabase()`。服务端回滚只回滚兼容 API，不直接回滚已执行的数据删除或签名证明。

## 13. 跨版本发布门禁

### 13.1 每个 P1/P2 工作包共有门禁

- P0 的 26 个用例不回归；P1 的 TC-F13/F14 在证据相关变更后重跑。
- 数据库迁移使用真实旧版本 fixture，升级失败不丢数据，旧导出仍可用。
- 新增页面完成键盘、读屏抽查、320 px、200% 字体和明暗主题检查。
- 新 API 有行级权限、请求大小、分页、限流、CSRF/CORS、审计和故障降级测试。
- 所有秘密仅存在服务端/密钥管理；前端、公开仓库、artifact 和日志扫描通过。
- feature flag 关闭时无死按钮，公开教程和本地学习路径不受影响。
- 回滚不删除高版本 IndexedDB，不撤销已确认本地数据，不通过跳过验签/权限维持可用。

### 13.2 额外专项门禁
